# 火富牛 MCP 配置
这个文件夹包含火富牛（fof99）MCP Server 的配置模板。
可选配合本仓库的 `fof99-` 系列 Skill 使用。配置后 AI 可调用火富牛基金数据接口；未配置 MCP 时，各通用型 Skill 仍可使用用户材料和其他可追溯来源独立工作。

---

## 前置条件
1. 你需要有好投科技火富牛平台的账号，并获得 `APP-ID` 和 `APP-SECRET`
2. 安装支持 MCP 的 AI 工具

---

## 配置后能做什么

配置成功后，AI 可以调用火富牛的基金数据工具，包括：
- 查询基金与管理人数据，核验来源并标准化字段
- 查询基金净值走势、业绩指标
- 基金持仓穿透、策略筛选
- FOF 组合分析
- 生成基金分析报告

基金数据查询与核验可优先配合 `fof99-fund-data-query` 使用；综合分析可配合 `fof99-fund-analysis` 使用；基金诊断、合规预审和 FOF 组合风险扫描也可按需使用火富牛 MCP 增强数据能力。
