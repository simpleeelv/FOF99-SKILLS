# 私募基金管理人尽调逻辑与报告框架

本文件提供不依赖火富牛 MCP 的完整尽调方法。无论使用用户材料、公开渠道、其他数据源或火富牛数据，都使用同一套证据、分析和报告逻辑。

## 1. 范围与模式

### `strategy`（默认）

适用于管理人初筛、策略研究和一般沟通。正式报告聚焦：管理人概况、股权与实控人、核心团队、策略逻辑、产品全景、代表业绩、重大风险和适用边界。

不默认加入运营控制清单、逐项证据状态、完整访谈问题、平台逐项对比和持续监测表；这些内容保留在内部底稿。

### `institutional`

仅在用户明确要求准入尽调、投委会、年度复核、运营尽调或合规复核时使用。可增加治理、利益冲突、交易与估值控制、服务商、信息技术、业务连续性、整改条件和监测触发器。

报告名称中出现“尽调”本身不等于需要机构级模式。

### 股权／创投管理人

用户明确要求 PE／VC 时，将业绩模块改为基金年份、认缴与实缴、投资项目、退出、估值、DPI、RVPI、TVPI、IRR、基金生命周期、关键人和利益冲突；不套用证券基金净值分析。

## 2. 来源策略

按事实类型选择最有权威性的来源，通常依次为：

1. 官方与一手来源：基金业协会、证监会及派出机构、企业登记、法院与执行系统、审计报告、合同、托管或估值材料；
2. 已授权的 FOF99／火富牛 MCP 结构化数据；
3. 管理人正式材料、签章问卷和书面回复；
4. 可追溯商业平台；
5. 管理人访谈与未独立核实的履历；
6. 可靠媒体与其他数据库线索。

来源权威性和新鲜度必须同时判断。来源冲突时保留各版本、日期和口径，不选择更有利的数值。

### 通用模式最低核验

在不使用火富牛 MCP 时，仍应完成：

- 法定名称、登记编号、登记状态、成立及变更信息；
- 股东、实控人、法定代表人和核心投资人员；
- 策略说明、投资流程、风险暴露、容量与适用环境；
- 可取得的产品目录、产品状态、成立日期和净值更新线索；
- 协会诚信／风险提示、监管措施、纪律处分及重大司法线索；
- 管理人材料中的关键主张与外部事实对照。

公开信息有限时输出可完成的报告，并明确哪些规模、产品、净值、团队或运营事项尚需管理人补充。不得因公开渠道未检索到记录而写成“不存在风险”。

### 商业平台

私募排排网、金斧子或其他商业平台只作补充：

- 使用法定名称和登记编号匹配主体；
- 记录页面、URL、访问日期、数据日期及登录限制；
- 对比产品名称、成立日期、策略、状态、净值日期和展示指标；
- 平台指标无法复算时标为“平台展示／未复算”；
- 不绕过登录、付费墙、验证码、robots 或服务条款；
- 默认最多使用一个平台，只有重大冲突才增加第二个平台。

## 3. 证据模型

每项影响结论的事实记录：证据 ID、主题、事实、来源、URL 或文件位置、来源类型、来源日期、检索日期、状态、限制与冲突。

| 状态 | 含义 |
|---|---|
| 已核验 | 当前一手来源或相互一致的可靠来源支持 |
| 管理人陈述 | 来自管理人或访谈，未取得独立验证 |
| 第三方线索 | 商业平台、媒体或数据库线索 |
| 存在冲突 | 关键来源在数值、日期、身份或口径上不一致 |
| 未取得 | 判断所需证据尚未获得 |

缺失证据不等于反面事实；“未取得”和“低风险”必须分开。

### 发现的写法

内部底稿按以下结构记录：

1. `事实`：证据直接说明什么；
2. `分析`：为什么重要及可能解释；
3. `影响`：对准入、投资、策略适用或监测的意义；
4. `后续动作`：需要的文件、确认、访谈或控制。

重大监管或诚信问题再增加 `反证／边界`：来源没有证明什么、是否存在整改、哪些推断不能做。

### 风险等级

- `高`：可能单独阻止准入或造成重大损失／合规后果，或关键冲突长期未解决；
- `中`：需要条件、整改或强化监测的重要弱点；
- `低`：影响有限且已有清晰控制；
- `信息不足`：证据不足，不能改写成低风险。

严重度与证据置信度分开。低置信度的严重线索应表述为“高影响待核实事项”，而不是已核实高风险事实。

## 4. 分析框架

### 执行摘要

- 一段管理人与策略画像；
- 3–6 条核心观察；
- 总体意见：`建议继续尽调`、`有条件推进`、`暂缓` 或 `不建议推进`；
- 证据完整度：`充分`、`部分充分` 或 `不足`；
- 最高风险和未解决阻断项。

身份、诚信或业绩真实性存在关键未决事项时，不给出无条件推进意见。

### 管理人与股权

核验法定名称、登记编号、登记与存续状态、办公地、管理类型、规模、产品数、股东、持股比例、实控人、关联方和重大变更。识别法定代表人、总经理、信息报送、投资和控制角色是否过度集中。

### 团队与关键人

核验创始人、高管、投资经理、风控合规人员的经历、任期、策略职责和稳定性。分析关键人依赖、人员变动、接班安排、团队与产品／策略数量是否匹配。管理人履历必须明确归因。

### 策略与投资过程

分析策略分类、收益来源、投资范围、数据与模型、主观环节、组合构建、交易执行、风控、复盘、持有期、换手、容量、杠杆、集中度和流动性。说明策略优势可能失效的市场环境和实施依赖。

### 产品全景

在数据允许时统计：

- 总产品数及分页完成度；
- 运作、正常清算、提前清算和其他状态；
- 一级／二级策略分布；
- 有净值、净值新鲜、停更和无净值产品；
- 规模与产品数变化；
- 主动管理与顾问／通道范围。

未完成全部分页时只描述“已返回范围”。选择代表产品前先说明产品全景和选择规则。

### 代表产品与业绩

默认最多使用 3 只代表产品，并优先选择：核心策略中历史较长的运作产品、能够检验风险／矛盾的产品，以及确有新增信息的近期产品。

必须披露产品覆盖率、净值覆盖率、选择规则和样本偏差。说明实盘／模拟、费前／费后、净值类型、来源、频率、起止日和基准。区间或频率不匹配时不得直接比较。

可分析收益、波动、夏普／卡玛、最大回撤、修复、年度／滚动收益、正收益占比和同策略分布，但只有输入和方法可复现时才使用。短样本、低频估值和平滑净值必须降低解释强度。

管理人策略指数不是可投资产品净值，宣传数字、账户数据、产品净值和报告自算结果必须分开。

### 风险、合规与一致性

检查：

- 登记、股权、实控人、人员和地址冲突；
- 关键人员频繁变化或未披露关联关系；
- 选择性业绩、回填、短样本、模拟结果冒充实盘；
- 净值停更、异常跳变、平台与团队净值差异；
- 策略描述与持仓、换手、风险暴露或收益行为不一致；
- 容量主张缺少流动性、冲击成本或赎回分析；
- 重大监管、诚信、诉讼、执行、投诉或舆情事项；
- 管理人拒绝提供合理核验材料。

监管／协会原文与新闻舆情分开，商业平台和媒体内容不得单独支持高影响结论。

## 5. 可选评分

只有用户要求或机构模板需要时评分。可使用五个维度，每项 20 分：

1. 团队稳定性；
2. 规模与策略容量；
3. 业绩真实性与一致性；
4. 言行一致性；
5. 合规与诚信。

每项同时列出正面证据、风险／反证、置信度和来源。缺失信息使用“暂不评分”或低置信度临时分，不计零，也不因未发现负面记录而加分。可信的重大监管事件、身份冲突或净值无法核验可覆盖总分。

如用户已有评分政策，优先使用用户政策；否则总分只能作为内部研究摘要，不得称作评级、信用评估或投资建议。

## 6. 双层交付

### 正式 HTML 报告

只呈现决策相关事实、分析、风险、结论、来源和重大限制。默认顺序：

1. 封面与文件控制；
2. 执行摘要；
3. 关键事件与管理人概况；
4. 股权与核心团队；
5. 策略逻辑与实施；
6. 产品全景与代表业绩；
7. 重大风险、反证与适用边界；
8. 结论、重要条件、来源和免责声明。

不显示工具名、API 参数、调用预算、失败日志、原始证据台账、内部访谈脚本或研究任务。技术失败只有在影响结论时才转写为专业的范围限制。

### 内部 HTML 底稿

记录数据路线、工具与来源覆盖、分页、失败、计算输入与方法、来源冲突、证据台账、补充材料、访谈问题、监测触发器和后续任务。页首标注“内部研究底稿｜不随正式报告提交”。

只有可能改变合理读者的判断、风险等级或依赖范围时，才把底稿问题提升到正式报告。

## 7. 结论语言

优先使用：

- `现有证据支持……`
- `管理人材料显示，但尚未取得独立验证……`
- `公开渠道未检索到相关记录，不等同于不存在相关事项……`
- `由于缺少……，暂无法判断……`

避免使用 `不存在风险`、`从未违规`、`业绩真实可靠`、`保证收益` 等绝对表述。

## 8. 完成检查

- 目标主体已唯一识别或歧义已明确；
- 所有重大事实有来源、日期和证据状态；
- 产品全景说明分页与覆盖率；
- 代表产品说明选择规则和限制；
- 业绩口径、区间、频率和来源明确；
- 重大负面事项已核验官方原文并写明边界；
- 正式报告和底稿内容分离；
- 结论与证据强度一致；
- 报告注明仅供尽职调查参考，不构成投资建议、法律意见或审计鉴证。
