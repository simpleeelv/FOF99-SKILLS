# 火富牛私募管理人尽调视觉规范

用于自包含的正式 HTML 尽调报告和内部 HTML 研究底稿。视觉定位为“机构研究档案”：专业、克制、证据导向。品牌识别应增强信息层级，不得把风险研究报告做成营销材料。

## 两类输出

- **正式报告**：突出结论、管理人概况、团队、策略、产品证据、重大风险和适用边界；隐藏工具、检索和内部待办。
- **内部底稿**：保留检索状态、覆盖率、来源冲突、失败记录、计算口径、访谈问题和后续任务；页首明确标注“内部研究底稿”。

两类输出共用同一数据模型和 HTML 生成器，避免数字、结论和版式分叉。生成器仅使用 Python 标准库。

## 品牌色与语义色

| 令牌 | 色值 | 用途 |
|---|---|---|
| 品牌主色 | `#E8663C` | 封面识别、章节编号、主标题、关键数字 |
| 品牌深色 | `#D1442A` | 重大风险、强调线、链接悬停 |
| 品牌浅底 | `#FFF0EB` | 摘要卡、标题底、重点提示 |
| 信息蓝 | `#4A90D9` | 来源、基准、辅助系列 |
| 审慎金 | `#F5A623` | 中风险、部分核验、需补充 |
| 核验青 | `#2EB5A6` | 已核验、低风险、完成状态 |
| 不确定灰 | `#8E8E93` | 未取得、无法核验、非适用 |
| 主文字 | `#1A1A1A` | 正文与数据 |
| 次文字 | `#666666` | 来源、口径、注释 |
| 边框 | `#EBEDF0` | 表格与卡片边界 |
| 模块底色 | `#FAFBFC` | 次级区块与交替行 |

风险等级和证据状态必须同时显示文字，不得仅靠颜色。涉及收益时可使用中国市场红涨绿跌，但要与“高风险深红”分开图例，避免语义冲突。

## 信息层级

正式报告建议顺序：

1. 封面：管理人、报告类型、用途、截止日、保密级别；
2. 执行摘要：总体意见、证据完整度、最高风险和 3–6 条核心观察；
3. 管理人概况与关键事件；
4. 股权、核心团队和关键人风险；
5. 策略逻辑、投资流程、风险暴露、容量和适用环境；
6. 产品全景与代表性业绩；
7. 重大风险、反证和适用边界；
8. 结论、重要条件、来源与免责声明。

内部底稿在正式内容之外增加编制审计、证据台账、冲突表、补充材料、访谈问题和监测清单。

## 卡片与排版

- 页面：白底，A4 纵向打印；正文最大宽度约 `1120px`。
- 卡片：圆角 `8px`，边框 `1px solid #EBEDF0`，阴影不超过 `0 1px 4px rgba(0,0,0,0.05)`。
- 正文：14px 左右，行高 1.6；打印版 9.5–10pt。
- H1：28–36px；H2：20–24px；H3：15–17px。
- KPI 卡最多 4 项，数字突出但不脱离口径和日期。
- 表格固定保留单位、日期、来源或状态列；长表允许横向滚动，打印时重复表头。
- 不使用装饰圆环、气泡、3D 图、仪表盘、强渐变或覆盖文字的浮动元素。

## 图表选择

| 问题 | 优先图表 | 要求 |
|---|---|---|
| 管理规模／产品数变化 | 双轴折线或上下分图 | 数据频率和时间点必须一致，否则分图 |
| 产品状态／策略结构 | 排序条形图 | 显示数量与样本总数，避免面积误导 |
| 净值与基准 | 折线图 | 区间、频率、净值来源和基准写入副标题 |
| 回撤 | 面积图 | `#FFF0EB` 填充、`#E8663C` 边线 |
| 年度收益 | 柱状图 | 正收益品牌红、负收益绿色并附数值 |
| 风险与证据矩阵 | 表格／热力图 | 状态同时使用文字与色块 |
| 事件与人员变化 | 时间表 | 用直线和表格，不用圆点装饰时间轴 |

净值与回撤必须基于同一序列；少于两个有效点时不画图。代表产品图不得暗示管理人全部产品表现。

## HTML 与打印

- 生成自包含 HTML：内联 CSS、内联 SVG、无需 CDN、外部字体或图表库。
- 正式报告和底稿必须可离线打开；链接使用完整 URL。
- 打印按钮只在屏幕显示，打印时隐藏。
- 使用 `@page { size: A4; }`；章节标题避免孤立在页底。
- 长 URL、中文表格和英文代码必须允许换行；图表横轴标签最多 6 个。
- HTML 应保留良好的 A4 打印样式，但 Skill 不依赖专门的 PDF 运行库。

## 降级规则

无法生成 HTML 时，使用 Markdown：摘要引用块 → 管理人表 → 团队表 → 策略结构 → 产品／业绩表 → 风险表 → 结论与来源。视觉降级不得删除证据状态、截止日和限制。
