# 火富牛综合基金分析

> 版本：1.0.3

对公募、私募、自建基金、直投组合和 FOF 执行综合分析。保留基金发现、净值走势、业绩指标、持仓分析、基金筛选和组合分析六类核心能力。先确定用户要解决的问题，再选择必要的数据和模块；不要为了“完整”而机械输出所有章节。

“火富牛”既用于品牌识别，也代表可选的数据增强能力。火富牛 MCP 不可用时，继续使用用户材料、其他已连接数据源和可追溯公开信息，不得要求用户必须登录特定平台。

## 数据路由

先遵守用户对来源的明确限制，再选择运行模式：

- **火富牛增强模式**：存在已授权的火富牛 MCP 查询工具时，主动用于基金身份、净值、指标、管理人、筛选、对比和可得 FOF 穿透数据。
- **混合核验模式**：用户材料与 MCP 同时存在时，以用户材料对应的实际对象和组合事实为主，用 MCP 补充或交叉核验；冲突项并列展示，不静默覆盖。
- **通用模式**：MCP 不可用、未授权、未命中或返回空数据时，使用用户文件、其他已连接数据源、官方披露和可追溯信息完成可支持的分析。

进入增强或混合模式时，必须读取并执行 [火富牛 MCP 路由](references/fof99-mcp-routing.md)。只调用查询、比较和图表渲染工具；不得上传净值、写入平台数据、创建产品或执行交易。注明实际运行模式、关键数据来源、截止日、覆盖范围和未命中项。

## 核心原则

- 先核验基金身份、份额类别、币种、净值口径、数据区间和基准，再比较指标。
- 区分事实、计算结果、分析判断、情景假设和待核验事项。
- 使用同区间、同频率、同币种、同费用与复权口径比较，无法对齐时明确限制。
- 不编造基金、净值、持仓、排名、规模、管理人、基准或市场事件数据。
- 不设置跨策略通用的“优秀”阈值；优先与适配基准、同策略样本和用户约束比较。
- 研究结论不等同于收益承诺、适当性判断或个性化买卖建议。

## 工作流程

### 1. 明确任务与对象

识别用户属于以下一种或多种需求：

1. 基金身份或基础信息查询
2. 净值走势与阶段表现分析
3. 业绩指标与风险收益解释
4. 多基金比较
5. 持仓、行业、策略或集中度分析
6. 基金或管理人筛选
7. FOF／组合分析与归因
8. 综合分析报告

提取基金名称或代码、基金类型、份额、币种、分析区间、基准、净值类型、用户关注点及输出形式。用户只提供名称时，使用可信来源解析代码与类型；出现同名、多份额、多币种或公私募冲突时列出候选并请求确认，唯一匹配且信息一致时直接继续。

### 2. 建立数据档案

读取并执行 [数据与分析方法](references/analysis-methodology.md)。至少记录：

- 产品或组合标识、类型、管理人、策略、成立日期
- 数据起止日、截止日、观察频率、币种、费用与复权口径
- 基准名称与代码、选择理由、可比区间
- 净值、指标、持仓、规模、申赎或穿透数据的来源与覆盖率
- 缺失、重复、停更、异常跳变、来源冲突和估值滞后

用户未指定区间时，默认分析近一年并在数据足够时补充今年以来和成立以来；必须明确这是默认选择。短于一年的结果不得直接外推为稳定年化能力。

### 3. 执行所需分析模块

#### 净值与业绩

使用完整时间序列或可信区间指标分析累计表现、阶段收益、回撤、波动、风险调整收益、相对基准表现和稳定性。读取 [基金指标解释](references/fund-metrics-guide.md)，避免仅凭单一指标排序。

#### 多基金比较

先统一比较口径，再比较净值、年度或阶段收益、回撤、波动、相关性和滚动指标。读取 [筛选与比较方法](references/screening-and-comparison.md)。样本区间不一致时，同时展示共同区间与各自可用区间，不混成一个排名。

#### 持仓与集中度

分析前五／前十大持仓、资产／行业／策略／管理人集中度、变化方向和未知比例。对低频或滞后披露注明持仓日期，不将过期持仓表述为当前暴露。

#### 基金筛选

将用户条件转成可复核的硬约束、排序指标和排除条件，再生成候选池。不得把数据源排名直接称为推荐名单。读取 [筛选与比较方法](references/screening-and-comparison.md)。

#### FOF 与组合

分析组合净值、权重、贡献、集中度、相关性、流动性、多层费用和可得穿透信息。必须读取 [组合与 FOF 分析](references/portfolio-and-fof-analysis.md)。仅有持仓时完成结构分析，不因缺少净值停止；无法穿透时显式展示未穿透比例。

### 4. 形成研究结论

按“主要发现—证据—解释边界—下一步”组织结论。对于筛选结果，说明为何入选、关键风险和需补充材料；对于比较结果，说明结论对区间、基准和频率的敏感性；对于综合报告，给出亮点、风险、反证和监测项，不给无条件买卖结论。

## 输出要求

- 输出正式报告时，必须读取并使用 [综合分析报告模板](references/report-template.md)，删除不适用章节和空表。
- 生成图表、可视化摘要或强调排版的成果时，必须读取 [火富牛综合分析视觉规范](references/fof99-visual-style.md)。纯 Markdown 只应用信息层级、表格、数据格式和语义标记，不强行模拟网页卡片。
- 先给摘要和关键指标，再给图表或证据表，最后给分析、限制、来源和后续事项。
- 百分比通常保留两位小数，净值通常保留四位；不得制造超过原始数据的精度。
- 每张图注明对象、区间、来源和一句核心解读。主基金使用品牌主色，基准使用灰色虚线；颜色之外同时使用标签、正负号或线型。
- 只有实际调用火富牛 MCP 时，才把对应数据标为“火富牛 MCP”。未调用时使用真实来源名称。

## 失败与安全处理

- 数据源不可访问、返回空值或格式错误时，说明受影响模块、已尝试路径和替代材料，继续完成其余部分。
- 火富牛 MCP 调用失败时只对相应数据项降级，不中止整个分析。
- 名称无法唯一定位时不得猜测代码；指标口径无法确认时标为待核验。
- 用户要求当前市场、法规、管理人或产品事件时，核验最新可信来源并注明检索日期。
- 不把历史业绩、回测、排名、模型结果或筛选分数表述为未来收益保证。
