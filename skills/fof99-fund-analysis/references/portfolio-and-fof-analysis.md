# 组合与 FOF 分析

## 分析层级

| 数据层级 | 可支持结论 |
|---|---|
| 持仓与权重 | 产品、管理人、策略、资产和币种集中度 |
| 持仓 + 净值 | 组合收益、回撤、相关性和近似风险贡献 |
| 持仓 + 交易／规模变化 | 收益贡献、资金流与调仓影响 |
| 完整穿透 + 条款 | 底层重复暴露、流动性、多层费用和期限匹配 |

先说明当前层级。缺少净值时不计算伪精确归因；缺少穿透时不将未知比例视为分散。

## 组合档案

记录组合名称、估值日、币种、总规模、持仓金额或权重、现金、负债、杠杆、基准、风险预算和流动性要求。权重不等于 100% 时先查明原因；只有在适合时才归一化，并保留原始权重。

## 结构分析

- 展示最大单项、前 3／前 5、HHI 或有效持仓数。
- 按产品、管理人、策略、资产、地区、币种和可得底层资产汇总。
- 识别同一管理人多产品、相同策略、重复底层和关联产品造成的“名义分散”。
- 将未分类、未穿透和日期过期的持仓单列。

## 业绩与归因

- 先分析组合整体净值、回撤和相对基准表现，再解释子基金贡献。
- 有日级或期间权重和交易数据时，使用匹配的归因方法；只有期末权重时，不声称完成精确历史归因。
- 将贡献拆为权重、持仓收益、现金、费用和可得交易影响；无法解释部分列为残差。
- 区分收益贡献和风险贡献。高收益贡献不代表低风险，高权重不一定是最大风险来源。

## 相关性与分散

使用对齐后的收益序列计算相关性，并说明重叠区间、频率和样本数。低频估值、净值平滑或错位更新会压低相关性。除常态相关性外，在数据足够时检查滚动和压力期相关性。

## 流动性与费用

按开放频率、通知期、锁定期、赎回到账、额度限制和暂停条款分层。多层基金结构需检查流动性叠加、信息滞后、管理费、托管费和业绩报酬等多层成本。条款未知时标为待核验，不假设随时可赎回。

## FOF 穿透

- `fof_sub_fund` 只适用于有权限且可识别的私募 FOF。
- 公募 FOF 使用定期报告、用户文件或其他可追溯持仓披露。
- 展示穿透日期、穿透层级、覆盖比例、重复暴露和未穿透比例。
- 底层持仓日期不一致时，不能将汇总视为同一时点精确快照。

## 输出结论

依次回答：组合靠什么获得收益、主要风险由谁贡献、分散是否有效、流动性是否匹配、哪些数据盲区可能改变结论。只在用户提供目标、期限和约束时讨论有条件的配置调整，并说明代价与残余风险。
