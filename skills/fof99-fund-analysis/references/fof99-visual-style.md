# 火富牛-基金全景投研分析视觉规范

用于单基金分析、多基金比较、基金筛选、持仓分析及 FOF／组合报告。目标是形成“专业、现代、数据清楚、品牌鲜明”的火富牛视觉体验，同时保持研究克制。

## 使用原则

- 白底为主，品牌红橙用于标题、主对象、关键数字和重点结论，避免大面积高饱和填色。
- 先摘要和 KPI，再展示图表或数据，随后解释证据、风险和边界。
- 纯 Markdown 使用标题、引用块、表格和状态文字建立层级；不使用 HTML 强行模拟卡片。
- HTML、PDF、DOCX 或网页成果可使用卡片、圆角、阴影和响应式布局。
- 没有图表工具时使用排序表和文字结论降级；不依赖特定 MCP 或渲染器。

## 色彩系统

| 令牌 | 色值 | 用途 |
|---|---|---|
| 品牌主色 | `#E8663C` | 主基金、关键 KPI、标题点缀、链接 |
| 品牌深色 | `#D1442A` | 重要风险、悬停、强调边线 |
| 品牌浅底 | `#FFF0EB` | 摘要和重点卡片背景 |
| 信息蓝 | `#4A90D9` | 第二系列、辅助信息、比较对象 |
| 暖金 | `#F5A623` | 观察项、临界状态、第三系列 |
| 下跌绿 | `#27AE60` | 仅用于收益或净值下跌语义 |
| 紫罗兰 | `#7B68EE` | 第四系列、策略维度 |
| 青绿 | `#2EB5A6` | 第五系列、分散或流动性维度 |
| 中性灰 | `#8E8E93` | 基准、待核验、次要信息 |
| 主文字 | `#1A1A1A` | 标题、正文、数据 |
| 边框 | `#EBEDF0` | 卡片、表格和分割线 |
| 模块底色 | `#FAFBFC` | 次级模块和表格交替行 |

区分两套语义：业绩图表中正收益用品牌红、负收益用 `#27AE60`；研究状态中高风险用深红、观察用暖金、待核验用灰色。最大回撤、波动率、费用率等不得仅按数值正负着色。颜色之外同时使用正负号、标签、线型或状态文字。

## 结构布局

1. 报告头部：对象、任务类型、区间、截止日和运行模式。
2. 摘要条：一句话结论、数据置信度和最重要边界。
3. KPI 区：最多 4–6 个与任务直接相关的指标。
4. 主图表：净值比较、筛选分布或组合风险主视图。
5. 辅助图表与证据表：每项后跟一至两句解释。
6. 亮点、风险、反证、下一步。
7. 数据来源、更新时间、口径和免责声明。

HTML 或文档卡片建议：圆角 `8px`，边框 `1px solid #EBEDF0`，阴影 `0 1px 4px rgba(0,0,0,0.06)`，内边距 `20px`，模块间距 `24px`。KPI 数字建议 `26–28px`，正文建议 `14px`。

## 场景与图表

| 场景 | 优先图表 | 要求 |
|---|---|---|
| 净值走势 | 折线图 | 主基金品牌色实线，基准灰色虚线，注明区间 |
| 收益比较 | 排序柱状图 | 正红负绿，显示零轴和数值标签 |
| 回撤 | 水下／面积图 | 深红边线、浅红填充，标记峰谷与修复 |
| 多指标比较 | 分组条形图／点图 | 优先于雷达图；统一量纲或标准化方法 |
| 持仓与策略 | 横向条形图／矩形树图 | 突出前五项、其他和未知比例 |
| 筛选结果 | 排序点图／散点图 | 同时表达收益、风险和规模，不只画单指标排名 |
| 相关性 | 热力图 | 显示数值；缺失使用灰色 `N/A` |
| 组合贡献 | 瀑布图／条形图 | 区分收益贡献、费用和残差 |

饼图只用于类别少于六项且总和明确为 100% 的构成。避免 3D 图、装饰性仪表盘和截断坐标轴。每张图包含标题、区间、来源和一句核心解读。

## 表格与可访问性

- 百分比通常保留两位小数，净值通常保留四位；数值右对齐、文字左对齐。
- 缺失显示“不可得”，冲突显示“来源差异”，不使用 `0` 替代。
- 排名必须显示比较区间、样本范围和排序指标。
- 字体优先级：`PingFang SC`, `Microsoft YaHei`, `Helvetica Neue`, `-apple-system`, `sans-serif`。
- 红绿组合必须辅以正负号、箭头、标签、线型或图案，保证黑白打印和色觉差异下仍可辨识。
