# 数据与分析方法

## 最小数据集

| 任务 | 最低所需数据 |
|---|---|
| 基础信息 | 基金名称或代码、类型、份额、管理人 |
| 净值走势 | 日期、复权净值或累计收益序列 |
| 指标分析 | 净值序列或带区间与口径的可信指标 |
| 多基金比较 | 各对象可对齐的日期、频率、币种和净值口径 |
| 持仓分析 | 持仓日期、名称、类别、权重或金额 |
| 组合分析 | 估值日、持仓、权重或金额、现金与负债 |

缺少最低数据时，说明需要补充的字段；已有部分数据时先完成可支持模块。

## 数据质量检查

1. 核验对象：名称、代码、份额类别、币种、基金类型和管理人。
2. 核验时间：起止日、截止日、净值频率、持仓日期和披露滞后。
3. 核验口径：单位／累计／复权净值，费前／费后，分红、拆分和份额变化。
4. 检查序列：缺失、重复、停更、异常跳变、非交易日和低频估值。
5. 核验基准：官方基准、分析基准和同类样本不能混称；说明选择理由。
6. 对齐比较：使用共同区间、共同频率和共同币种；无法对齐时降低置信度。

## 计算口径

- 简单区间收益：`期末复权净值 / 期初复权净值 - 1`。
- 年化收益只在区间和频率足够时计算，并注明年化方法；短区间以区间收益为主。
- 波动率使用收益序列和明确的年化因子；日、周、月频不得混用。
- 最大回撤同时记录峰值、谷值、回撤深度、持续期和修复状态。
- 超额收益、Alpha、Beta、跟踪误差和信息比率必须绑定明确基准。
- 相关性只在足够重叠、同频和可比的收益序列上计算；低频估值可能低估风险。

## 证据层级

按任务选择证据，不机械认定单一来源始终优先：

1. 用户提供的实际净值、持仓、组合和合同材料用于确定分析对象。
2. 已授权的结构化数据库或 MCP 用于补充和交叉核验。
3. 基金管理人、交易所、监管机构和基金定期报告用于核验正式事实。
4. 可追溯第三方信息作为补充，注明日期和限制。

来源冲突时列出数值、日期、口径和可能原因，不选择对结论更有利的一方。将证据强度标为高、中或低，并说明缺失信息会影响哪些判断。

## 默认区间

用户未指定区间时，以近一年作为主区间；数据足够时补充今年以来、近三年和成立以来。基金存续不足时使用实际区间。跨基金比较同时提供共同区间，避免因成立时间不同产生不公平排名。
