# 基金指标解释

所有指标必须与区间、频率、净值口径、无风险利率和基准一起解释。不要仅凭单一指标给出优劣结论。

| 指标 | 主要回答 | 解释边界 |
|---|---|---|
| 区间收益 | 观察期赚了多少 | 受起止点影响，不代表持续能力 |
| 年化收益 | 将较长区间折算为年收益 | 短区间年化会放大偶然性 |
| 年化波动率 | 收益波动程度 | 低频或平滑估值可能低估风险 |
| 最大回撤 | 历史峰值至谷值最大损失 | 同时看持续期、修复期和数据频率 |
| 夏普比率 | 单位总波动获得的超额回报 | 对非正态、平滑净值和无风险利率敏感 |
| 索提诺比率 | 单位下行风险获得的回报 | 需说明目标收益或最低可接受收益 |
| 卡玛比率 | 年化收益相对最大回撤 | 对单一极端回撤和区间选择敏感 |
| Alpha | 控制基准暴露后的收益 | 依赖基准、模型、频率和样本长度 |
| Beta | 对基准波动的敏感度 | 非线性或动态暴露无法被单一 Beta 完整描述 |
| 跟踪误差 | 相对基准收益的波动 | 需确认基准适配；主动基金高值不必然不佳 |
| 信息比率 | 单位跟踪误差的超额收益 | 区间短或基准错误时解释失真 |
| 相关系数 | 同向波动程度 | 不代表因果；压力期和低频估值会改变结果 |
| 下行风险 | 低于目标的波动 | 目标值必须明确 |
| 偏度／峰度 | 收益分布的不对称与尾部 | 样本短时不稳定，不能单独预测尾部损失 |
| VaR／CVaR | 给定置信水平下的尾部损失 | 模型依赖强，历史最差不等于未来上限 |
| 周／月胜率 | 正收益期占比 | 高胜率可能伴随少数大额亏损 |

## 组合解释规则

- 收益与回撤同时看：高收益若主要来自更高市场暴露，应与基准和 Beta 一起解释。
- 波动与流动性同时看：低波动可能来自低频估值、估值滞后或缺失数据。
- 夏普与卡玛同时看：分别反映波动效率和回撤效率，不能相互替代。
- Alpha 与基准适配一起看：不合适的基准会制造虚假 Alpha。
- 相关性与压力期一起看：常态低相关不保证危机时分散有效。

## 表达方式

使用“高于／低于适配基准或同策略样本”“在该区间表现更稳健”“证据不足”等条件化语言。除非用户提供投资政策或明确阈值，不使用跨策略固定标准判定“优秀”“安全”或“值得投资”。
