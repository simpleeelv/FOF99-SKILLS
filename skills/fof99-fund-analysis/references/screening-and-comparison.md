# 基金筛选与比较方法

## 筛选流程

1. 将用户目标拆为硬约束、排序指标、排除条件和待核验条件。
2. 明确基金范围：公募／私募、策略、币种、地区、成立时间、规模、开放状态和数据截止日。
3. 先应用硬约束形成候选池，再用同区间指标排序；不要先排名再补条件。
4. 检查净值完整度、存续期、份额类别、清盘样本和缺失数据，降低幸存者偏差。
5. 对前列候选核验基金身份、管理人、基准、规模、风险和流动性，不把数据库分数直接当作推荐。

## 条件分类

| 类型 | 示例 | 处理方式 |
|---|---|---|
| 硬约束 | 策略、规模、成立年限、开放状态 | 不满足则排除 |
| 风险约束 | 最大回撤、波动、流动性 | 明确区间和容忍边界 |
| 收益目标 | 区间收益、年化收益、超额收益 | 与风险和基准联合使用 |
| 稳定性 | 滚动收益、胜率、修复期 | 检查多窗口而非单点 |
| 管理人 | 管理规模、经验、产品数量 | 核验披露日期和口径 |
| 数据质量 | 完整度、更新频率、截止日 | 不达标时排除或降级 |

## 多基金比较

- 身份对齐：确认同类份额、币种、净值类型和费用口径。
- 时间对齐：使用共同区间；同时可展示各自成立以来结果，但不能混排。
- 基准对齐：比较绝对收益时可使用统一市场基准，评价策略能力时优先适配基准。
- 频率对齐：日、周、月收益不得直接混算；私募低频净值与公募日频比较时说明平滑偏差。
- 样本对齐：注明候选池数量、数据覆盖率、筛选日期和是否包含清盘基金。

## 常见偏差

- 只保留仍存续产品导致幸存者偏差。
- 用不同成立日期的“成立以来”收益直接排名。
- 只按收益筛选而忽略回撤、波动、流动性和容量。
- 对短历史基金使用年化指标制造虚假精度。
- 把同一基金不同份额当作多个独立样本。
- 把平台评分、排名或历史第一名写成投资建议。
