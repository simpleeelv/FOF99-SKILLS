# 火富牛-基金数据查询与核验

> 版本：1.0.3

为基金研究、报告、合规预审和组合分析提供可追溯的数据底座。负责识别对象、查询数据、核验口径、标准化字段和交付查询回执；不替代深度分析、基金筛选结论、合规判断或投资建议。

“火富牛”既用于品牌识别，也代表可选的数据增强能力。未连接火富牛 MCP 时，继续使用用户文件、其他已连接数据源、官方披露和可追溯公开信息；没有可用数据源时，输出明确的补数清单，不虚构结果。

## 数据路由

先遵守用户对数据来源、隐私和联网的明确限制，再选择运行模式：

- **火富牛增强模式**：存在已授权的火富牛 MCP 查询工具时，用于基金、管理人、净值、指标、持仓、组合、指数及相关市场数据查询。
- **混合核验模式**：用户材料与 MCP 同时存在时，以用户材料对应的对象和业务事实为主，用 MCP 补充或交叉核验；冲突项并列展示，不静默覆盖。
- **通用模式**：MCP 不可用、未授权、未命中或返回空数据时，使用用户文件、其他授权连接、管理人／交易所／监管机构披露和可追溯来源完成查询与核验。

进入增强或混合模式时，必须读取并执行 [火富牛 MCP 路由](references/fof99-mcp-routing.md)。只调用查询、比较和只读计算工具；不得上传净值、写入平台、创建产品或执行交易。

## 核心边界

- 返回数据和数据质量判断，不把查询结果直接解释为基金优劣或投资推荐。
- 区分原始字段、标准化字段、派生计算、来源说明和待核验项。
- 不编造基金、管理人、净值、持仓、排名、规模、基准或市场数据。
- 不把空值、未命中或无权限解释为零；统一标记为“不可得”“未命中”或“无权限”。
- 不把数据库默认基准自动当作合同业绩比较基准。
- 未经用户要求不返回超出任务所需的大量原始记录、个人信息或授权组合信息。

## 查询流程

### 1. 建立查询单

提取并确认：

- 查询对象：基金、份额、管理人、组合、指数或市场指标
- 基金类型：公募、私募、自建、私募 FOF、直投／模拟／实盘组合
- 所需字段：基本信息、净值、指标、持仓、规模、人员、风险记录或市场数据
- 时间要求：单一估值日、区间、截止日、频率和时区
- 口径要求：单位／累计／复权净值、费前／费后、币种、基准和年化方式
- 交付格式：摘要、Markdown 表、CSV／XLSX 字段、JSON 结构或查询回执

用户只提供名称时，先解析代码与类型；出现同名、多份额、多币种或公私募冲突时列出候选并请求确认。用户只说“最新”时记录实际数据日期，不把查询日期当作数据截止日。

### 2. 选择查询路径

读取 [查询场景与字段](references/query-workflows.md)，只加载与请求相关的场景：

1. 基金或管理人身份与基本信息
2. 净值与业绩指标
3. 多基金对比数据
4. 持仓、FOF 穿透与组合数据
5. 管理人尽调数据
6. 指数、期货基差和对冲成本相关数据

使用最少必要调用完成任务。分页结果超过用户所需范围时不要自动获取全部；说明当前页、页大小、总量和是否需要继续。

### 3. 校验与标准化

必须读取 [数据质量与标准化](references/data-quality-and-normalization.md)，检查：

- 代码、份额、基金类型、管理人和策略是否一致
- 数据起止日、截止日、频率、币种、费用与复权口径
- 缺失、重复、停更、异常跳变、分红、拆分和估值滞后
- 多对象是否使用共同区间、共同频率和可比基准
- 来源之间是否存在数值、日期或口径冲突

只有在方法和输入明确时才计算派生字段。派生值必须记录公式、输入来源和计算区间，不伪装成原始数据源字段。

### 4. 交付查询回执

输出正式结果时，使用 [数据查询回执模板](references/output-template.md)。至少包含：

- 查询对象与请求字段
- 实际运行模式与使用来源
- 返回字段、数据区间、截止日和覆盖率
- 未命中、无权限、不可得和冲突字段
- 标准化或派生计算说明
- 可复用的数据表或结构化字段

生成强调排版的查询报告或数据面板时，读取 [火富牛数据查询视觉规范](references/fof99-visual-style.md)。纯 Markdown 只应用信息层级、状态标签和表格规范。

## 失败与安全处理

- 单个查询失败时只将对应字段降级，不中止其他可完成部分。
- 火富牛 MCP 鉴权失败或无数据时切换到混合或通用模式，不要求用户必须安装或登录。
- 无可用外部数据源时，列出最小补数清单、字段格式和可接受材料，不猜测填充。
- 来源冲突时保留各版本、来源、日期和口径，标记“待确认”。
- 需要当前市场、管理人、监管或产品事实时，核验最新可信来源并记录检索日期。
- 不输出认证凭据、请求头、连接地址或其他敏感配置。
