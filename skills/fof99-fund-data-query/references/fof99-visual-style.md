# 火富牛基金数据查询视觉规范

用于数据查询回执、字段覆盖表、数据质量面板和结构化查询成果。视觉定位为“专业数据控制台”：清楚、紧凑、可追溯，品牌感服务于查询效率，不把数据表装饰成营销报告。

## 使用原则

- 第一屏或第一页先展示查询状态、对象数、字段覆盖率、实际数据截止日和主要缺口。
- 白底为主，品牌红橙用于标题、查询主题和关键数字；数据状态使用独立语义色。
- 来源、截止日、口径和状态与数值同等重要，不缩成不可读脚注。
- 纯 Markdown 使用摘要引用块、状态文字和紧凑表格；HTML、PDF、DOCX 或网页可使用卡片和固定表头。
- 无图表工具时以覆盖矩阵、排序表和文字提示降级，不影响查询结果。

## 色彩与状态

| 令牌 | 色值 | 用途 |
|---|---|---|
| 品牌主色 | `#E8663C` | 标题、关键数字、主对象、链接 |
| 品牌深色 | `#D1442A` | 查询失败、严重数据冲突、强调边线 |
| 品牌浅底 | `#FFF0EB` | 查询摘要与重点提示背景 |
| 完成色 | `#2EB5A6` | 查询完成、字段有效返回 |
| 部分完成 | `#F5A623` | 覆盖不完整、数据过期、需补充 |
| 信息蓝 | `#4A90D9` | 来源、口径、辅助信息、第二系列 |
| 不可得／未命中 | `#8E8E93` | 空数据、无权限、待确认 |
| 主文字 | `#1A1A1A` | 标题、正文、数据 |
| 次文字 | `#666666` | 字段说明、来源、口径 |
| 边框 | `#EBEDF0` | 卡片和表格分隔 |
| 模块底色 | `#FAFBFC` | 次级区块和交替行 |

查询状态固定显示文字：`完成`、`部分完成`、`待确认`、`无可用数据`。不得只靠颜色表达。收益数据如需着色，可在独立的业绩表或图中使用中国市场红涨绿跌；不要把“正收益红”与“查询失败红”放在同一图例。

## 信息结构

1. **查询头部**：查询主题、运行模式、查询时间和实际数据截止日。
2. **状态卡片**：查询状态、对象覆盖率、字段覆盖率、冲突数、待补字段数，最多五项。
3. **结果数据表**：主要交付内容，固定展示单位和数据日期。
4. **覆盖与质量面板**：缺失、停更、异常、冲突和无权限状态。
5. **来源与口径**：来源、查询类别、分页范围和标准化说明。
6. **补数清单**：缺失字段、影响、所需材料和替代来源。

HTML 或文档卡片建议：圆角 `8px`，边框 `1px solid #EBEDF0`，阴影 `0 1px 4px rgba(0,0,0,0.04)`，内边距 `16–20px`，模块间距 `20px`。数据表应优先保证列宽、换行和打印可读性。

## 可视化选择

| 数据问题 | 优先图表 | 要求 |
|---|---|---|
| 字段覆盖率 | 横向进度条／矩阵表 | 同时显示分子和分母，不用只有百分比的仪表盘 |
| 对象查询状态 | 堆叠条形图 | 完成、部分、未命中、无权限分别计数 |
| 数据新鲜度 | 排序点图／时间轴 | 标注实际数据日期，不只显示“较新／较旧” |
| 缺失模式 | 热力图 | 缺失使用灰色或纹理，显示字段与对象名称 |
| 来源差异 | 哑铃图／差异表 | 同时展示两来源数值、日期和口径 |
| 净值数据交付 | 折线图 | 仅在用户需要预览时生成，完整数据仍以表格或文件交付 |

不使用 3D 图、速度表式仪表盘、词云或会弱化来源和口径的信息装饰。图表标题包含对象和日期，图下注明来源与覆盖范围。

## 表格与可访问性

- 表格优先展示对象、字段、值、单位、状态、数据日期和来源；不要省略状态列。
- 百分比和净值保留与原始数据匹配的精度，不为视觉整齐制造精确度。
- 长时间序列默认提供摘要预览和完整结构化数据，不在正文堆满行。
- 字体优先级：`PingFang SC`, `Microsoft YaHei`, `Helvetica Neue`, `-apple-system`, `sans-serif`。
- 状态色必须辅以文字、图标或纹理，保证黑白打印、窄屏和色觉差异下仍能识别。
