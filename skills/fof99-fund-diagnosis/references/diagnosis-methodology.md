# 数据与诊断方法

在计算指标或形成结论前使用本方法。只呈现能够由来源、原始序列或明确计算口径支持的结果。

## 数据质量门槛

| 检查项 | 处理方法 |
|---|---|
| 数据截止日 | 明确报告使用的最后有效日期，不把未来发布日期误当净值日期 |
| 观察频率 | 标记日、周、月或不规则净值；低频数据可能低估波动和回撤 |
| 缺失与停更 | 统计缺口和最长停更期；关键阶段缺失时降低结论置信度 |
| 异常跳变 | 核验分红、拆分、估值调整、申赎和数据录入，不直接视为投资损益 |
| 复权口径 | 区分单位净值、累计净值和复权净值，避免重复计算分红 |
| 费用口径 | 区分费前与费后，确认管理费、业绩报酬和多层费用是否计入 |
| 币种口径 | 统一币种；涉及汇率时说明本币收益与资产收益差异 |
| 比较区间 | 基金、基准和同类样本采用共同起止日及相同频率 |

## 指标解释

- **区间收益**：用于实际持有区间，不隐含持续性。
- **年化收益**：仅在区间足够长、频率合理且口径明确时使用；短区间同时展示原始区间收益。
- **年化波动**：受数据频率和估值平滑影响，不等于全部风险。
- **最大回撤**：同时报告峰值、谷值、持续期、修复日和最长水下期。
- **夏普比率**：说明无风险利率、频率和年化方法；不要跨不同策略直接排序。
- **索提诺比率**：说明目标收益率或最低可接受收益率口径。
- **卡玛比率**：结合最大回撤区间解释，不使用脱离策略的固定合格线。
- **Alpha／Beta**：明确基准、回归区间和样本频率；显著性不足时不作确定归因。
- **相关系数**：检查滚动变化，避免用全样本相关性掩盖压力期共振。

## 诊断置信度

- **高**：核心净值、指标、基准、费用和关键背景完整且口径一致。
- **中**：主要数据可用，但持仓、归因、同类样本或管理人资料部分缺失。
- **低**：净值周期短、更新不规则、关键数据未经核验或只能依赖宣传材料。

报告结论的确定性不得高于数据置信度。

## 比较规则

- 优先选择策略、风险来源、币种和可投资范围相近的基准或同类样本。
- 不把不同成立日期的“成立以来”指标直接横向排名。
- 不将单一牛市或熊市区间概括为长期能力。
- 不因一个指标领先就下结论；至少联合收益、回撤、修复、波动和数据质量判断。
- 同类排名必须说明样本范围、数量、数据源、截止日期和是否存在存续偏差。

## 压力阶段选择

从基金实际存续期选择与策略相关的压力阶段。记录精确起止日、市场背景、基准表现、基金回撤与修复情况。若基金在该阶段尚未成立或缺少数据，不使用替代年份冒充实测结果。
