# 火富牛 MCP 路由｜基金报告合规预审

仅在当前工具目录存在已授权的火富牛 MCP 查询工具时使用。优先匹配 `mcp__fof99_mcp_mall_stream__*`，也兼容 `mcp__fof99_mcp_mall__*`；按工具后缀和实际参数说明识别能力。

## 1. 使用边界

- MCP 只用于事实与数据主张的交叉核验，不用于法律定性、法规检索或最终合规批准。
- 禁止调用上传、写入、创建、更新、删除或交易执行工具。不要把用户报告或底稿上传到 MCP。
- 用户明确限定仅使用其材料时，不调用 MCP。
- 结果为空、过期、冲突或无权限时标记“未核验”，不得推断报告错误或产品无风险。

## 2. 核验路由

| 报告主张 | 工具后缀 | 核验重点 |
|---|---|---|
| 基金名称、代码、类型 | `get_fund_code` | 私募／公募、份额和同名歧义 |
| 私募／公募基本信息 | `fund_info`／`gm_fund_info` | 名称、成立日、管理人、规模日期、正式基准 |
| 净值序列 | `fund_platform_price`、`fund_company_price`／`gm_fund_price` | 区间、净值来源、复权口径、最新日期 |
| 业绩指标 | `get_fund_factor`／`get_gm_fund_factor` | 收益、波动、回撤、修复、Alpha、Beta 等口径 |
| 指数 | `get_index_code`、`index_price`、`get_index_factor` | 指数身份、比较区间和指标 |
| 多基金比较 | `compare_factors`、`compare_returns`、`compare_annual` | 同区间、同频率、同净值类型和排序口径 |
| 私募管理人 | `get_company_code`、`company_info`、`company_scale`、`company_manager` | 登记编号、规模日期、核心人员和披露口径 |
| 私募 FOF 穿透 | `fof_sub_fund`、`fof_sub_fund_deals` | 持仓日期、覆盖范围、底层交易记录 |

`fof_sub_fund` 仅适用于私募 FOF；不得用它声称已核验公募 FOF 的底层持仓。私募 FOF 返回无数据时，改用用户估值表或正式披露并标记限制。

## 3. 差异处理

对每个关键数据项记录：报告原值、核验值、两者截止日、来源、口径和差异。依次排查：

1. 基金代码、份额类别或同名产品是否匹配。
2. 日期、币种、费前／费后和单位是否一致。
3. 单位净值、累计净值、复权净值是否混用。
4. 平台净值与团队净值是否采用不同来源。
5. 收益区间、年化方法、无风险利率和净值频率是否一致。
6. 基准是合同披露的复合基准、系统映射指数还是营销比较指数。

无法解释的差异列为“待核验”，不要自动采用 MCP 值替换报告。默认指数与基金正式业绩比较基准不一致时，只能作为参考指数。

## 4. 输出与降级

输出“数据核验范围”小节，列明运行模式、调用工具类别、数据截止日、核验覆盖率、差异项和未命中项。只有实际采用的字段才能标注“火富牛 MCP”。

调用失败或无结果时，继续完成不依赖该数据的表述和披露预审，并给出最小补证材料。不得要求非火富牛用户安装 MCP 才能获得预审结果。
