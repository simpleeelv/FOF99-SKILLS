# 风险信号灯与分级规则

信号灯用于安排复核优先级，不等于产品质量评级、收益预测或买卖指令。

## 1. 判定顺序

1. 优先使用用户风险预算、投资政策、合同约束和已批准阈值。
2. 其次使用适配基准、同策略历史和组合自身分布进行相对判断。
3. 两者均缺失时，可提出诊断初始阈值，但必须标注“待确认”，不得假装为行业统一标准。
4. 对结论进行合理情景敏感性检查；轻微调整假设即可变色时，降低置信度或标黄。

## 2. 四种灯号

| 灯号 | 含义 | 典型处理 |
|---|---|---|
| 🔴 红灯 | 已突破明确约束，或可信证据显示重大且紧迫的风险 | 立即核验数据与风险来源，评估临时控制措施 |
| 🟡 黄灯 | 接近边界、趋势恶化、暴露偏高或存在需限期澄清的异常 | 指定负责人、补充数据并设复核日期 |
| 🟢 绿灯 | 在当前范围与证据下未发现显著异常 | 按计划监测；不表述为“安全”或“无风险” |
| ⚪ 灰灯 | 数据缺失、陈旧、冲突或方法不适用 | 补数或核验，不得并入绿色比例 |

## 3. 信号记录字段

每条信号至少包括：

- 风险维度与对象
- 当前指标或事实
- 阈值、基准或比较方法
- 灯号与变化方向
- 数据截止日和来源
- 证据置信度
- 潜在组合影响
- 下一步动作、责任角色和复核期限（信息可得时）

## 4. 参考判断框架

### 集中度

观察最大单项、前 3／前 5、HHI、有效持仓数，以及管理人、策略和底层暴露的穿透后集中。若权重集中与风险贡献集中同时出现，优先级通常高于仅权重集中。

### 相关性

观察高相关对、高相关簇、滚动相关性和压力期相关性。先排除样本短、低频估值和估值滞后；同一风险源的多个产品不能因名称不同而被视为分散。

### 回撤与风险预算

比较当前回撤、历史最大回撤、压力损失、修复时间和用户最大可承受损失。临近预算但仍在界内通常为黄灯；可信结果显示已突破明确硬约束时才考虑红灯。

### 风险贡献

比较资本权重与风险贡献占比。小权重但贡献大量组合风险的持仓应突出显示。估计不稳定时使用区间或定性分级，不给出过度精确的灯号。

### 流动性

比较各期限可变现资产与同期现金需求、赎回压力或负债。已知的重大期限错配可为红灯；条款未知必须为灰灯，而不是绿灯。

### 数据质量

关键净值停更、份额匹配不确定、估值日错位、权重无法闭合、穿透覆盖低或条款陈旧，应单独出灯。数据质量问题可能降低其他信号的置信度。

## 5. 合并与升级规则

- 同一根因产生的多个指标合并成一个风险主题，避免重复计数。
- 红灯数量不直接等于组合总等级；考虑损失规模、紧迫性、可逆性和证据强度。
- 灰灯多时，不得给出整体绿灯。
- 单一低置信度红灯应表述为“疑似重大风险，需立即核验”，而不是确定事实。
- 从黄灯升级为红灯，应记录触发事件或阈值突破；从红灯降级也应记录新增证据或风险缓释措施。

## 6. 行动分层

- **P0 立即核验**：可能触及硬约束、重大流动性错配、数据异常导致风险不可见。
- **P1 限期处置**：暴露接近上限、相关性或回撤持续恶化、穿透集中明显。
- **P2 持续监测**：当前未越界但对某一情景敏感，或需等待后续数据验证。
- **补充数据**：对应所有灰灯，明确所需字段和可替代材料。

若用户要求降低风险，只讨论可行路径及其代价，例如降低集中会影响收益目标，增加流动性会产生机会成本，降低相关性可能引入新的基差或管理人风险。未经用户授权，不执行交易或外部操作。
